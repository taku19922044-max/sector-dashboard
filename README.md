# 東証33業種ダッシュボード（無料運用版）

## できること
スマホ対応のランキング、前営業日・5/20/60営業日・全期間比較、業種推移グラフ、数値に基づく市場総括、CSV取込と保存。GitHub Pagesで公開でき、GitHub Actionsで毎平日17:15 JSTにデータ更新処理を試みます。祝日やデータ未配信の日は架空の値を追加しません。

**注意:** この配布物に実際の東証33業種データは含まれません。無料・合法・安定的な33業種指数CSVの自動配信元は未確定です。データソースを設定するまではデモ表示です。AI総括は無料のルールベース文章生成であり、外部ニュースを読む生成AIではありません。

## 公開
1. このフォルダの内容をGitHubの公開リポジトリにアップロード。
2. Settings → Pages → Deploy from a branch → main / (root) を選択。
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で閲覧。
4. Actionsを有効にし、必要なら Actions → Update sector market data → Run workflow で手動実行。

## データ自動取得の設定
許諾を得た **HTTPS** CSV配信URLがある場合、リポジトリの Settings → Secrets and variables → Actions → New repository secret に `SECTOR_CSV_URL` を登録。取得CSVは `date,industry,close` のヘッダーを持ち、33業種の**指数終値**が日付ごとに揃っている必要があります。個別銘柄の平均騰落率は使用しないでください。データ配信元の自動取得・再配布・公開規約を必ず確認してください。

URL配信がない場合は `inbox/` にCSVを置き、Actionsを手動実行するかローカルで `python update_market.py` を実行できます。アプリ画面のCSVアップロードも可能ですが、ブラウザ内のみの更新です。CSVファイルをリポジトリに公開してよい利用許諾が必要です。

`data/latest.csv` と `data/summary.json` は有効な33業種の全日データが確認されたときだけ生成されます。部分欠損の日は除外します。新規CSVに重複する同一日・業種がある場合はエラーにします。

## データの仕様
`date,industry,close` 形式。例：
```
date,industry,close
2026-11-13,小売業,2519.71
```
この1行だけでは33業種が揃わないため公開されません。1日につき33行必要です。2営業日以上あれば騰落率が計算されます。

## 生成AIの追加について
現状の総括は完全無料の数値ベース。OpenAI API等によるニュース要因分析は**未接続**です。追加する場合はActionsのSecretsにAPIキーを置き、サーバー側でのみAPIを呼び出し、ニュースの出典と日付を検証してください。ブラウザのHTMLや公開リポジトリに秘密鍵を書かないでください。
